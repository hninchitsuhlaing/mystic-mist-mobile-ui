# Mystic Mist Mobile App UI/UX Design

## Overview

Mystic Mist is a mobile e-commerce application designed for a luxury perfume brand.

The project focuses on creating an intuitive shopping experience through modern user interface design and user-centered navigation.

## Features

- User Authentication
- Product Catalog
- Product Categories
- Shopping Cart
- Checkout Flow
- Product Reviews
- Account Management

## Tools Used

- Figma
- UI Design
- UX Design
- Wireframing
- Prototyping
